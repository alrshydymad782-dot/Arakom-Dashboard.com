# أراكم — لوحة تحكم أنظمة التعرف على لوحات المركبات

لوحة تحكم ويب لكاميرات التعرف على اللوحات (LPR/ANPR) التي تتصل عبر **MQTT**، ومصممة للوحات السعودية ودول الخليج.
تعمل على الجوال مثل التطبيقات (تُثبَّت على الشاشة الرئيسية) وعلى الكمبيوتر.

## المكونات

| الجزء | الوصف |
|---|---|
| **لوحة العميل** `/app` | أجهزته وحالتها، زر فتح البوابة، المركبات لحظياً، السجل والبحث والتصدير إلى Excel، قوائم السماح والحظر، إشعارات للمركبات المحظورة وانقطاع الأجهزة |
| **لوحة المدير** `/admin` | إدارة العملاء والاشتراكات، ربط الكاميرات بالعملاء، حسابات الدخول، سجل كل القراءات، حالة خادم MQTT، سجل العمليات |
| **خادم MQTT** | Mosquitto (يستقبل رسائل الكاميرات) |
| **HTTPS** | Caddy يصدر شهادة مجانية تلقائياً (ضرورية لتثبيت التطبيق والإشعارات على الجوال) |

### كيف يعمل
1. الكاميرا ترسل رقم اللوحة إلى Mosquitto.
2. لوحة التحكم تستقبل الرسالة، تحوّل اللوحة إلى صيغة موحدة (عربي ↔ إنجليزي)، وتقارنها بقائمة العميل.
3. إذا كانت اللوحة مسموحاً لها، يُرسَل أمر فتح البوابة إلى الكاميرا تلقائياً.
4. تظهر القراءة فوراً على جوال العميل.

**أوضاع البوابة** لكل جهاز: فتح تلقائي للمسموح لهم فقط / فتح للجميع عدا المحظورين / فتح يدوي فقط.

**الكاميرات الجديدة** تظهر تلقائياً في لوحة المدير بمجرد اتصالها، ثم تربطها بالعميل.

## ⚠️ التوافق مع ملفات المصنع

حالياً يتعرف النظام تلقائياً على الصيغ الشائعة لكاميرات LPR الصينية (مثل `AlarmInfoPlate` / `PlateResult`) وعلى صيغ JSON البسيطة.
لضمان التوافق التام مع كاميراتك يجب مطابقة:
- **المواضيع (Topics)**: تُعدَّل في ملف `.env` (`MQTT_TOPIC_RESULT`، `MQTT_TOPIC_HEARTBEAT`، `MQTT_TOPIC_COMMAND`).
- **صيغة أمر فتح البوابة**: `MQTT_OPEN_GATE_PAYLOAD` في `.env`.
- **صيغة رسالة القراءة**: في ملف واحد فقط هو `server/parser.js`.

## التشغيل على السيرفر (الإنتاج)

المتطلبات: سيرفر VPS بنظام Ubuntu (يكفي 2GB RAM)، ونطاق (Domain) يشير إلى عنوان IP الخاص بالسيرفر.

```bash
git clone <رابط المستودع> arakom && cd arakom
bash deploy/setup.sh
```
السكربت يثبّت Docker، ويسألك عن النطاق وكلمات المرور، وينشئ حسابات MQTT، ثم يشغّل كل شيء.

بعدها:
1. افتح `https://نطاقك` وادخل بحساب `admin`.
2. اضبط كل كاميرا (من صفحة إعداداتها) على:
   - عنوان الخادم: عنوان IP السيرفر أو النطاق، المنفذ `1883`
   - المستخدم: `camera` وكلمة المرور التي اخترتها
3. ستظهر الكاميرا في «الأجهزة»، فتربطها بالعميل.
4. أنشئ للعميل حساباً من «العملاء»، وأرسل له الرابط واسم المستخدم وكلمة المرور.

> افتح المنافذ 80 و443 و1883 في الجدار الناري للسيرفر.

## التجربة على جهازك (بدون كاميرات)

```bash
npm install
npm run dev          # يشغل اللوحة + خادم MQTT تجريبي مدمج
npm run simulate     # في نافذة أخرى: يحاكي كاميرات ترسل لوحات
```
افتح http://localhost:3000 — المستخدم `admin` وكلمة المرور `admin123`.

يتطلب Node.js الإصدار 22.5 أو أحدث.

## تثبيت التطبيق على الجوال
- **آيفون**: افتح الرابط في Safari ← زر المشاركة ← «إضافة إلى الشاشة الرئيسية».
- **أندرويد**: افتح الرابط في Chrome ← «تثبيت التطبيق».

## اللوحات السعودية
يقبل النظام اللوحة بالعربي (`ح ب ا ١٢٣٤`) أو بالإنجليزي (`ABJ 1234`) أو بالاثنين معاً، ويحوّلها لنفس الصيغة،
باتباع المقابلة الرسمية للأحرف (ا=A، ب=B، ح=J، د=D، ر=R، س=S، ص=X، ط=T، ع=E، ق=G، ك=K، ل=L، م=Z، ن=N، هـ=H، و=U، ى=V).
لوحات دول الخليج الأخرى تُحفظ وتُطابق كما هي.

## هيكل المشروع
```
server/
  index.js      واجهة API والصفحات
  mqtt.js       الاتصال بـ MQTT، منطق فتح البوابة
  parser.js     ← ملف التوافق مع رسائل المصنع
  plates.js     معالجة اللوحات السعودية
  db.js         قاعدة البيانات (SQLite)
public/         واجهة العميل والمدير (تطبيق ويب PWA)
deploy/         إعدادات Mosquitto و Caddy وسكربت التثبيت
tools/simulator.js  محاكي كاميرات للتجربة
```
